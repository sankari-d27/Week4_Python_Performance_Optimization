
# Week 4 - Performance Optimization in Python

## Project Description

This project demonstrates Python application performance
optimization through data processing.

## Requirements

- Python 3.8 or later
- No external Python packages required

## Run Original Application

python original_app.py

## Run Optimized Application

python optimized_app.py

## Run Benchmark

python benchmark.py

## Run Profiler

python profiler.py

## Run Automated Tests

python -m unittest test_application.py

## Generate ZIP Archive

python generate_report.py

## Optimization Techniques

1. Dictionary-based aggregation
2. Set-based duplicate detection
3. Single-pass processing
4. Reduced redundant computations

## Expected Result

The optimized application should produce the same
statistical results as the original application
while reducing unnecessary processing.
